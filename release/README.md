# Ready-to-host release

The `small-measure` folder is compiled and ready to copy to an HTTPS web server for ArcGIS Enterprise 11.5.

Deploy the complete folder unchanged, then register its hosted `manifest.json` URL as an **Experience Builder widget** item in the customer portal.

See [Deploy to ArcGIS Enterprise 11.5](../docs/site/install.md) for the complete customer workflow.
